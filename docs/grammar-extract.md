# 詞的 in-context 文法資訊（`data/html` → `out/grammar`）

> 2026-11-02。把光明寺教蔵 html 裡「逐詞文法表」抽成兩種 TSV，給
> [`D:\2026\sz`](file:///D:/2026/sz) 做語法／詞彙分析用。
> 抽出程式：`src/extract-grammar.mjs`；來源是 `data/html/*.html.gz`（見 `crawl-log.md`）。

## 1. 為什麼要抽

光明寺的每一頁都是 Excel 匯出的表格：一句巴利原文，接著一或多個「逐詞分析區塊」，
區塊表頭有兩種：

| 區塊 | 表頭 | 欄位 |
|---|---|---|
| 名詞／形容詞 | `語 語根 品詞 語基 性 数 格 意味` | 8 欄 |
| 動詞（述語） | `述語 語根 品詞 活用 態 数 人称 意味` | 8 欄 |

後面接 `訳文`（日譯）與 `メモ`（注）。抽出來就是「某一句裡、某個詞的形態與語法角色」，
也就是 in-context grammar。

**注意：這些表是人工剪貼的，錯很多**（詞對不上句子、欄位貼錯、重複列、缺註）。
本程式只**照實抽出**、不改值，可疑處放 `flags`，讓下游自己決定要不要用。

## 2. 產出

| 檔 | 內容 |
|---|---|
| `out/grammar/sentences.tsv.gz` | 每個單元（句子／標題／注）一列 |
| `out/grammar/tokens.tsv.gz` | 每個被標注的詞一列 |
| `out/grammar/chapters.tsv` | 每章統計與 flag 數（未壓縮） |

sz 用的副本：`D:\2026\sz\data\kmj-grammar\`（同內容＋`README.md`）。

### 2.1 `sentences.tsv.gz`

```text
sent_id  folder  chapter  unit  kind  label  pali  ja  memo
```

- `sent_id`：`<分冊>/<章>/<章內序號>`，例 `an/an01c01/12`（唯一鍵）。
- `kind`：`sentence`（有 `1-1.` 這種段號）／`unlabeled`（沒段號但有詞表，
  多半是標題或經名）／`note`（沒有詞表，通常是注文或導覽殘留）。
- `label`：段號，例 `1-7.`；沒有就是空。
- `pali`：巴利原文（HTML 實體已解成字元，`&nbsp;` → 空白）。
- `ja`：日譯；`memo`：注記。

### 2.2 `tokens.tsv.gz`

```text
sent_id  tok  start  ctx  form  form_clean  root  pos  stem  gender  number  case  person  voice  meaning  block  flags
```

| 欄 | 說明 |
|---|---|
| `tok` | 該單元內第幾個詞（1 起算，照表格順序） |
| `start` | 在**正規化後**句子（去標點、轉小寫、去變音符號）裡的起始位置；`-1` 表示沒對上 |
| `ctx` | 對位方式：`s` 完全相符、`f` 去變音符號後相符、`c` 往回找（複合詞／貼錯段落）、`b` 在區塊引文裡 |
| `form` | 表格裡的形式（可能含標點，例 `rūpaṃ.`） |
| `form_clean` | 去標點、小寫、去變音符號的比對鍵 |
| `root` | 語根（巴利語動詞／名詞詞根，來源寫法） |
| `pos` | 品詞：`名／代／形／動／副／不変／数／接／間／不定`…（來源也會出現 `名過分`、`現分` 這種複合值） |
| `stem` | 名詞是**語基**（`a`／`ant`／`i`…），動詞是**活用**（`現`／`過`／`完`…） |
| `gender` | 性：`男`／`女`／`中`／`男中`…（來源偶有 `中（男）`、`男→中` 這種註記） |
| `number` | 数：`単`／`複`／`帯`（=両数） |
| `case` | 格：`主／対／具／与／属／処／呼／副対／持`，以及 `依（属）`、`有（持）` 這類複合標記 |
| `person` | 人称（只有述語）：`一／二／三` |
| `voice` | 態（只有述語）：`能／受／中`… |
| `meaning` | 意味（日語釋義） |
| `block` | `nom`（名詞區塊）／`pred`（述語區塊） |
| `flags` | 逗號分隔的品質旗標，見 §3 |

## 3. 品質旗標（重點）

| flag | 意思 | 建議 |
|---|---|---|
| `nf` | 這個詞**在句子裡找不到**（連去變音符號也找不到） | 多半是人工貼錯；分析詞形時可先用 `nf` 排除 |
| `sandhi` | 靠去變音符號或近似對位才找到（連音：`Na`+`ahaṃ` → `Nāhaṃ`） | 可用，`start` 是近似值 |
| `compound` | 順序倒著找到的（複合詞拆解：`pubba`+`anta`+`kappikā` ← `pubbantakappikā`） | 可用，但 `tok` 順序不代表句序 |
| `back` | 位置比前一個詞更前面（人工重排或貼錯） | 順序分析時要排除 |
| `order` | `start` 比前一個詞小 1 以上 | 同上 |
| `dup` | 和前一個詞完全相同（重複列） | 可去重 |
| `nopos`／`badpos` | 品詞空白／不是合法值（例 `女`、`能` 貼到品詞欄） | 少見，直接視為缺值 |
| `badgender` | 性別欄不是性別（例 `能`、`複`、`単` 貼錯欄） | 少見 |
| `nomeaning` | 意味空白 | 少見 |

## 5. 已知的來源錯誤型態

> **作者 2026-11-02 指示：經文重複句很多，少許錯誤影響不大。**
> 所以不必為了那 1~2% 的 `nf`／欄位貼錯回頭改資料或補標；
> 做好旗標、讓下游能濾掉就夠，重複段落本來就不會再標一次。

抽的過程中看到、值得 sz 知道的：

1. **重複段落不再標注**：同一段在第 2、3 經重複出現時，表格只標第一次，
   第二次常只有「語」欄或整段空白 → 那些句子沒有詞（28,589 句）。
2. **複合詞拆解與連音**：表格把 `pubbantakappikā` 拆成 `pubba`／`anta`／`kappikā`，
   句子裡卻是連寫；`Nāhaṃ` 拆成 `Na` + `ahaṃ`。這些是正常的，用 `compound`／`sandhi` 標。
3. **欄位貼錯**：把「態」的值（`能`）貼到「性」欄、把「性」的值（`女`）貼到「品詞」欄。
4. **整句貼進詞欄**：偶爾整句被貼進「語」欄（`nf` 或 `compound` 會抓到）。
5. **頁面重貼**：分頁處會把同一句再貼一次（本程式會把它併回原單元，不另立新句）。
